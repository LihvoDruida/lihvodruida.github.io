# Перевірка релізу 4.0.0 · 15.10.2026

- `npm run build:ci`: успішно — TypeScript, 12 тестів, перевірка контенту та production build.
- Збережено 7/7 гайдів, 8/8 адонів і 2/2 спільнот. Markdown, YAML та оригінальні assets залишені у звичних для редактора шляхах.
- Standalone: 104 упаковані серверні JS-файли збігаються з фінальними файлами збірки після повторного build.
- Chromium: 122 успішні перевірки. Дев’ять сторінок перевірені на ширинах 1440, 768, 390 і 320 px: HTTP 200, один h1, без горизонтального виходу за екран.
- Функціональні сценарії: мобільне меню й перехід, пошук гайдів/складу/заявок, debounce пошуку, довідник професій, вимога BattleTag для Horde, захист кнопки надсилання від дублювання та номер відстеження.
- API-тести: одночасні запити, TTL, bounded stale, cooldown, відновлення, відмова при неправильній схемі та перевищенні 4 MiB, відсутність приватних контактів у списку, query allowlist, ETag/304, датований fallback гільдії.

Браузерні інтеграційні сценарії використовували тестові відповіді за чинним контрактом дашборда. Перехоплено один тестовий POST, реальних записів і Discord-повідомлень не створено. Production standalone запускався локально. Docker CLI та доступ до production PostgreSQL/Discord/VPS у цій сесії відсутні; контейнерне розгортання та живе приймання тут не виконувалися.

Для живого приймання після запуску: подати одну погоджену тестову заявку → перевірити її в дашборді та Discord → змінити статус → перевірити оновлення на сайті протягом наступних циклів синхронізації. Окремо звірити склад, сезон, прогрес і опублікований розклад із дашбордом.
